# BlindShell App Updater 0.1.0 beta

This first beta helps people browse, install and update Android apps on a
connected BlindShell phone from a keyboard-accessible Windows application.

- Search, categories and installed apps share one results list.
- F1 opens the readme; first-time setup explains the phone's Service menu and
  the Windows app's Prepare USB button.
- Installation progress is announced through JAWS or accessibility
  notifications and reports Android's installation-session percentage when
  available.
- The app attempts to add third-party menu entries for newly installed apps.

Download the beta ZIP, extract it, and read **Start Here.txt** before opening
the EXE. This is an unsigned, supervised beta; Windows may show an
unknown-publisher warning. USB preparation has been tested on one Android 10
BlindShell configuration. NVDA, additional phone models, and the end-to-end
installation experience need further testing. Some apps are unavailable or
incompatible. This independent project is not affiliated with BlindShell, Meta,
Google, or Aurora.

The beta uses Aurora OSS GPlayApi, which its upstream project describes as
reverse-engineered and for educational and research purposes. Third-party
distribution terms and release signing need review before wider production
distribution. Source and notices are included in the ZIP and repository.
